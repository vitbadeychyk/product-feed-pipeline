# Інтеграція EVA

## Результат

Модуль формує `data/output/eva/eva_feed.xml` у тому самому YML/XML-форматі,
що й чинний модуль Rozetka. Генератор повторно використовує перевірені функції
Rozetka для описів із Supabase, залишків, фотографій, штрихкодів і параметрів.

## Файли

- `scripts/eva/category_map.py` — відповідність категорій постачальника
  категоріям EVA та перелік категорій для ігнорування.
- `scripts/pricing/eva_pricing.py` — базові й промотарифи EVA та розрахунок цін.
- `scripts/eva/export_feed.py` — відбір товарів і формування XML.
- `data/output/eva/eva_feed.xml` — готовий фід EVA.

## Ціноутворення

Для робочої ціни використовується базовий тариф EVA. Промотарифи збережені
окремо для майбутнього перемикання. Формула:

1. база постачальника: `original_price * 0.78`;
2. додається націнка 700 / 1000 / 1500 / 2000 грн залежно від початкової ціни;
3. сума ділиться на `1 - тариф EVA`;
4. результат округлюється вгору до 100 грн;
5. `price_old` дорівнює фінальній ціні +30% та округлюється вгору до 100 грн.

## Ігнорування категорій

Тимчасово не передаються:

- `83` — Ліжка та манежі;
- `39` — Ваночки та горщики;
- `63` — Ролики та захист.

Категорії, для яких EVA ще не має відкритої відповідності, також не
потрапляють у фід. Це не впливає на Rozetka та Epicentr.

## Автоматичне оновлення

GitHub Actions викликає `python -m scripts.eva.export_feed` після генерації
Rozetka. Готовий файл входить до загального автоматичного commit і push через
`git add data/output/`.
